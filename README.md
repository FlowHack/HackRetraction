# HackRetraction

Плагин OrcaSlicer для генерации теста на ретракцию. По заданным параметрам строит
G-code калибровочного куба: тесты с увеличивающимся втягиванием по сторонам, ступеньки
скорости, обдува и температуры по высоте.

## Возможности

- Генерация G-code теста на ретракцию по параметрам (диаметр сопла, размеры стола,
  высота слоя, коэффициент потока, скорость печати/перемещения, температуры, обдув).
- Подтягивание базовых параметров и стартового/конечного G-code из профиля принтера
  (кнопка «Подтянуть параметры»); все параметры имеют значения по умолчанию.
- Определение типа экструдера (bowden/direct) для стартовых скоростей и втягивания.
- Подгрузка ранее сгенерированного G-code — параметры заполнятся автоматически.
- Экспорт G-code в выбранное пользователем место (поле пути) + копирование в буфер.
- Визуализация: вид сверху (значения втягивания) и сбоку (ступеньки скорости,
  обдува, температуры).
- Настройки: тема (auto/тёмная/светлая), размер и шрифт, язык (RU/EN/SR),
  язык комментариев в G-code.

## Установка

Установка выполняется через подписку OrcaCloud на странице плагина:
[https://cloud.orcaslicer.com/p/XXXXXXXX](https://cloud.orcaslicer.com/p/XXXXXXXX)

Альтернативно — локально через wheel: поместите `hackretraction-<версия>-py3-none-any.whl`
в `data_dir()/orca_plugins/` и перезапустите OrcaSlicer.

> `data_dir()` — папка конфигурации OrcaSlicer. В Windows обычно
> `%APPDATA%\OrcaSlicer`; открыть её можно через **File → Configuration folder**.

## Запуск

1. Откройте диалог плагинов: **File → Plugins**.
2. Установите флажок (чекбокс) слева от **HackRetraction** — плагин активируется.
3. Раскройте плагин, нажав на стрелочку в его строке.
4. Справа появится кнопка запуска — нажмите её, откроется окно генератора.

Использование: задайте параметры (или нажмите «Подтянуть параметры»), нажмите
**Generate**, затем **Copy** (в буфер) или укажите путь в поле и нажмите **Save**.

## Разработка

- Тесты: `pytest tests/`
- Линт: `PYTHONPATH=stubs pylint hackretraction --fail-under=9.0`
- Типы: `PYTHONPATH=stubs pyright hackretraction`
- Сборка: `python -m build --wheel && python tools/patch_wheel.py dist/*.whl`
