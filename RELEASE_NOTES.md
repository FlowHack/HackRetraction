# HackRetraction 0.1.0

Первый публичный релиз плагина калибровки ретракции для Orca Slicer.

## ✨ Возможности

- 🧪 **Генерация калибровочной башни**: дистанция втягивания растёт по периметру квадрата (точки на стенках), скорость / температура / обдув меняются по высоте блоками.
- 👁️ **Живое превью** на HTML/CSS: вид сверху (значения втягивания вокруг квадрата) и вид сбоку (монолитные блоки башни с параметрами) — обновляется мгновенно при вводе.
- ⚙️ **Подтягивание параметров из профиля**: диаметр сопла, размеры стола, высота слоя, коэффициент потока, скорости, температуры, стартовый/конечный G-code; определение типа экструдера (bowden/direct).
- 🧮 **Рекомендованные параметры**: под выбранный профиль по умолчанию предлагаются оптимально рассчитанные значения — можно сразу генерировать башню.
- 🔒 **Блокировка шагов**: только один инкрементальный параметр за раз (скорость / температура / обдув), остальные поля блокируются с пояснением в тултипе; валидация перед генерацией.
- 💾 **Экспорт**: меню после «Сгенерировать GCODE» — копирование в буфер или сохранение в файл; загрузка ранее сгенерированного G-code с восстановлением параметров.
- ❓ **Встроенная помощь**: красная кнопка «?» с пошаговым руководством по калибровке и чтению башни.
- 🔔 **Уведомления-тосты** вместо статус-строки: результат каждого действия виден в правом верхнем углу.
- 🎨 **Настройки**: тема (auto/тёмная/светлая), размер и шрифт, язык интерфейса (RU/EN/SR), язык комментариев G-code.
- 🛡️ **Защита от отрицательных шагов** инкрементальных параметров.
- 📊 **Таблица параметров в G-code** выводится сверху вниз (верхний блок башни — первая строка).
